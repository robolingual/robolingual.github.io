# マニュアル用の画像

`MANUAL_v1.0.md` に差し込む画像を、ここに置きます。

## 使い方

**`manual.html`（公開用ページ）の場合**

下表のファイル名で画像をこのフォルダに置くだけです。ページ側の編集は不要で、
画像が見つかった図版だけが自動で差し替わります。置いていない図版は枠のまま残ります。

**`MANUAL_v1.0.md`（Markdown版）の場合**

1. 画像をこのフォルダに置く
2. 該当箇所の `<!-- 画像スロット: ... -->` を探す
3. コメントの中にある `![...](docs/images/xx.png)` の行を、コメントの外に出す

| ファイル名 | 中身 |
|---|---|
| `00-overview.png` | アプリ全体のスクリーンショット |
| `01-source.png` | CHOOSE / PRESET / TRANSLATE まわり |
| `02-translate.png` | TRANSLATE後の波形（Ready表示） |
| `03-pads.png` | 16パッド全体。1つ点灯した状態 |
| `04-pan.png` | 左側のPANノブ4つ |
| `05-bpm.png` | 16パッドがテンキーに変わった状態 |
| `06-speed.png` | 右側の速度スライダー |
| `07-chaos.png` | 八卦盤。HOLD / 0 LOCK 込み |
| `08-slip.png` | 波形を押さえて白い帯が出ている状態 |
| `09-player.png` | PLAY / STOP / REC / SAVE |

ファイル名は目安です。変えるときは `MANUAL_v1.0.md` 側のパスも合わせてください。
