01

はじめる

PRESET 1 PRESET 2 PRESET 3 を押すと、読み込みから生成まで自動で進みます。まずはこれで。

自分の音源を使うときは CHOOSE でファイルを選び、TRANSLATE を押します。対応形式は WAV / MP3 / M4A / AAC / MP4 / M4V / MOV。

BPM は TRANSLATE の前に決めてください。プレイ中に変えると音程まで変わります。

動画を使うとき

画面に表示される READ VIDEO を押すと動画からの音声抽出が始まりますが、動画の長さぶん時間がかかります。終わるまで画面を開いたままにしてください。

02

16パッド

縦4段がキャラクター（NINJA / KILLER / BANKER / WITCH）、横4列がバリエーション（A・B・C・Ex）です。

Ex はワンショットの必殺フレーズです。ループしないかわりに連打できます。

4段は同じ8小節をループし続けます。

03

スリップループ

演奏中に上部モニターに触れると、触れた場所に応じた刻みで全体をループさせます。押さえたままスライドさせると刻みが変化します。

左中右
上段11/321/16
下段1/21/41/8

数字は1拍を何分割するか。指を離すと元の演奏に戻ります。時間は止まっていないので、離した時点から続きます。

04

八卦盤

ロボ会話の方向性を決めます。中心がドライ（原音）で、外周へ向かうほど深くかかります。

操作子動作
HOLDONにすると、指を離した場所に張り付いたままになります。
0 LOCK指を離したときに戻る場所を、現在地に設定します。初期値は中央＝ドライ。

0 LOCK で軽く歪ませた場所を戻り先にしておくと、その状態を基準に出たり戻ったりできます。

05

保存する

SAVE は直前に触っていたものによって中身が変わります。

表示保存されるもの条件
SAVE ZIP16パターンの WAV をまとめた ZIP16パッドを最後に操作
SAVE WAV録音した演奏 1本の WAVPLAY / STOP / REC を最後に操作

狙った方を保存したいときは、先にその側を一度操作してから押してください。●︎ REC は八卦盤もスリップループも、聴こえているまま録れます。

06

その他

項目内容
MIDI画面右上に MIDI が出ていれば、市販のMIDIパッドで16パッドとPANを操作できます。押すと画面の指示どおりに叩いて覚えさせる流れになります。
SKIN画面右上の SKIN から、背景の板を好きな画像に差し替えられます。
ショートカットPCのみ。Z で HOLD の切り替え、X で 0 LOCK。

B

困ったときは

音が出ない

画面をどこか一度タップしてから ▶︎ PLAY を押してください。ダメならリロード。

パッドが押せない

「Ready」と表示されるまでお待ちください。

生成結果が気に入らない

もう一度 TRANSLATE を押すと、別の16パターンになります。
