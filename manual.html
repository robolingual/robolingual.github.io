Robolingual

v1.0 Owner's Manual

音源をひとつ渡すと、4人が別々の流儀で演奏し直します

ROBOLINGUAL は、手持ちの音声や動画から「ロボ語」を生成し、その場で組み替えて演奏するブラウザ上の楽器です。インストールは不要で、スマートフォン・タブレット・PC のいずれでも動作します。

対応環境iOS / Android / PC ブラウザ 入力形式WAV MP3 M4A AAC MP4 M4V MOV ループ長8小節 固定 音源パターン16（4キャラ×4種）

01

音声を読み込む

素材になる音を決めます。

プリセットを使う

PRESET 1 PRESET 2 PRESET 3 のいずれかを押すと、読み込みから生成まで自動で進みます。

自分の音源を使う

  1. CHOOSE を押してファイルを選びます。
  2. 波形が表示されたら読み込み完了です。

音声ファイルのほか、動画ファイルからも音声を抜き出せます。対応形式は WAV / MP3 / M4A / AAC / MP4 / M4V / MOV です。

02

ロボ語を生成する

TRANSLATE を押すと、4キャラクター × 4バリエーション＝16パターンが生成されます。波形の下に「Ready」と表示されれば完了です。

同じ音源でも、押すたびに異なる16パターンができます。

生成前に BPM を決めておいてください。生成されるロボ語のテンポは、そのときの BPM を基準に決まります。

↑RESTART は、生成したパターンを保ったままループを頭から鳴らし直します。

03

パターンを選ぶ

16個のパッドがこの楽器の中心です。縦4段がキャラクター、横4列がバリエーションという並びになっています。

4人のキャラクター

段性格
NINJAしなやか。伸ばしと上下のピッチベンドが主役で、終盤に向けて滑らかに解けていきます。
KILLER硬く攻撃的。短く密な連打を身上とし、終盤ほど畳みかけるスタッターが増えます。
BANKER生真面目。確率に頼らず、拍ごとに確実にキックを打ちます。後半は16分単位まで正確さを上げます。
WITCH気まぐれ。骨格を踏まえつつ、不規則に間引きながら音を飛ばします。

4つのバリエーション

列内容
A短く、密で、乾いた発音。
B長く、丸く、アタック少なめ。柔らかいエンベロープ。
C4スライスの固定パターンが主体。
Exワンショットの必殺技。押した瞬間に一発だけ鳴ります。

操作

  • パッドを押すと、その段がそのバリエーションに切り替わります。
  • 点灯中のパッドをもう一度押すと、消灯してその段が止まります。
  • Ex は点灯したままにはならず、押した瞬間だけ光ります。
  • Ex は連打すると頭の一撃が繰り返され、フィルインになります。

どう組み替えても頭がずれません。

04

PAN

画面左の4つのノブで、キャラクターごとの左右の定位を決めます。上から NINJA / KILLER / BANKER / WITCH の順です。ノブはドラッグして回します。

ループ（A・B・C）もワンショット（Ex）も、同じキャラクターであれば同じ位置から鳴ります。4人を左右に散らすと、それぞれの動きが聴き分けやすくなります。

05

BPM

設定できる範囲は 60〜260 です。BPM を変えると、波形上の拍の目盛りも追随します。

スマートフォン・タブレット

BPM を押すと、16パッドがそのままテンキーに変わります。

  • 開いた直後に数字を押すと、今の値を消して打ち直しになります。
  • 今の値を直したいときは、先に ⌫ か ◀ を押します。
  • ◀ ▶ でカーソルを動かし、途中に数字を挿し込めます。
  • ENTER で確定、CANCEL で取り消しです。BPM をもう一度押しても取り消せます。

PC

BPM の欄をクリックして、そのまま打ち込めます。テンキーは出ません。

06

MASTER SPEED

画面右の縦スライダーで、全体の再生速度を ⅓×〜3.0× の範囲で変えます。上が遅く、下が速い配置です。生成時に設定した BPM が基準になります。

  • ドラッグすると連続的に変化します。
  • 目盛りをタップすると、その速度へ一度で移動します。
  • ダブルクリックで 1.0× に戻ります。

上部には現在の倍率と、換算後の BPM が表示されます。

07

カオスパッド

画面下部の八卦が描かれた盤で、音を空間ごと歪ませます。中心がドライ（原音）で、外周へ向かうほど深くかかります。

方向かかり方
SOCIETY 上金属的インダストリアル。低域を固くブーストし、中音の声を前に出します。
PARAISO 右ピッチを上げ、ディレイと長く煌めくリバーブ。終わらない安らぎ。
TOKIO 下グリッチとボコーダーみ。きらめく未来。
ZION 左荘厳。パイプオルガン的な持続に、コーラスと超ロングリバーブ。

地獄ゾーン

斜め45度付近、隣り合う2方向がほぼ均等に混ざる帯は「地獄ゾーン」です。専用の過激な処理がかかり、さらにそのとき鳴っている音から拾った亡霊のような声が薄く混ざります。

操作方式

パッドは相対方式です。触った場所へ飛ぶのではなく、触ってから動かした分だけ現在地が動きます。

操作子動作
HOLD OFF指を離すとゼロ地点に戻ります（初期状態）。
HOLD ON指を離した場所に張り付いたままになります。
0 LOCK戻る先であるゼロ地点を、現在地に設定します。初期値は中央＝ドライです。

0 LOCK で軽く歪ませた場所をゼロ地点にしておくと、その状態を基準に出たり戻ったりできます。

08

スリップループ

演奏中に波形を指で押さえると、直前に鳴っていた音がその場で繰り返されます。いわゆるビートリピートです。

押した瞬間から遡って4拍ぶんが素材になります。頭は拍に合うので、キックなどのアタックがループの先頭に来ます。

刻みを変える

波形は2段×3列の6区画に分かれています。押さえたまま指をずらすと刻みが変わります。

左中右
上段11/321/16
下段1/21/41/8

刻みを変えても音の出頭は動きません。指を滑らせても途切れません。

切り取られている範囲は、波形の上に白く光る帯で示されます。刻みが細かいほど点滅が速くなります。

最も細かい 1/32 だけは、白い芯のまわりが赤と黄に交互に発光します。

指を離すと元の演奏に戻ります。時間は止まっていないので、離した時点から続きます。

09

プレイヤーと保存

操作子動作
▶︎ PLAY再生します。
■︎ STOP停止します。
●︎ REC演奏を録音します。カオスパッドもスリップループも、聴こえているまま録れます。
SAVE直前に操作していた対象に応じて内容が変わります。

SAVE の切り替わり

表示保存されるもの条件
SAVE ZIP生成した16パターンを個別の WAV にまとめた ZIP16パッドを最後に操作した場合
SAVE WAV録音した演奏1本の WAVPLAY / STOP / REC を最後に操作した場合

狙った方を保存したいときは、先にその側を一度操作してから SAVE を押してください。

困ったときは

音が出ない

画面をどこか一度タップしてから ▶︎ PLAY を押してください。

パッドが押せない

「Ready」と表示されるまでお待ちください。生成が終わると押せるようになります。

生成結果が気に入らない

もう一度 TRANSLATE を押すと、別の16パターンになります。

動画を読み込むと音が小さい

波形は見やすいよう自動で拡大表示しています。音そのものは変わりません。
