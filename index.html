Robolingual RC1

Human voice → Robolingual. Four bars, automatic groove translation.
1. Source
VOICE / AUDIO / VIDEO
Required
声だけの素材を推奨。iPhoneのMOV/MP4もブラウザが音声を読めれば使用可能。
ORIGINAL / RHYTHM REFERENCE
Optional
拍を拘束せず、BPMとグルーヴの参考にする。
素材を読み込むと波形が出る。
2. Translate
自動編成
四小節固定。発話を言葉単位で自動採掘し、四つ打ちを骨格に、ブレイクコア連打と三連符をアクセントとして自動配置する。
人間が調整するのは必要時のBPMだけ。採掘範囲・素材単位・文法・小節数は装置側で決定する。
3. Long Voice (Experimental)
長母音化／反復伸長／終端強打「!!!」
会話音声ではなく、末尾を音程維持〜微上昇で長く伸ばし、終端を強打するDJ煽り声へ改造する。
4. Robolingual A / B
4 bars / phrase groove
NORMALは自然な反復と休符。HARDは連打・切断・微ズレを強める。
5. Combine (Experimental)
煽り一声 → 機関銃パッド
参甲と参乙を生成すると、完成物同士を一つのDJフレーズとして連結できる。
Robolingual RC1 / Single-file browser app. 音声は外部送信しない。Chrome / Edge推奨。動画対応はブラウザのデコーダーに依存。RC1はボーカル分離・原曲差し替えをまだ行わない。
